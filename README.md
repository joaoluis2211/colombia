# 🌎 Site sobre a Colômbia

Projeto desenvolvido para a disciplina de Programação Web 3.

## 📌 Descrição

Este projeto consiste na criação de um site informativo sobre a Colômbia, utilizando HTML e Bootstrap. O objetivo é apresentar aspectos culturais, turísticos e gerais do país, aplicando conceitos de desenvolvimento web responsivo.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5

## 🎯 Funcionalidades

- Página inicial com introdução ao país
- Seções sobre cultura, turismo e curiosidades
- Layout responsivo (adaptável para celular e desktop)
- Uso de componentes do Bootstrap (navbar, cards, grid, etc.)
